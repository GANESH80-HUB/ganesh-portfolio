# Ganesh Portfolio

A personal portfolio website showcasing my work across software development, Generative AI, frontend development, UI/UX design, and my ongoing learning in cloud technologies.

## Features

- **Interactive Three.js Technology Network**: A rotating 3D node sphere in the hero section displaying core skills and mapping navigation scroll targets.
- **Responsive Portfolio Design**: A premium dark-themed layout built with responsive components for desktop, tablet, and mobile views.
- **Animated Hero Section**: Dynamically typed introduction phrases emphasizing focus areas.
- **Interactive Skills**: Clean, reactive glow layouts highlighting my technical abilities.
- **Project Case Studies**: Interactive popup modal details presenting Problems, Solutions, Tech Stacks, and Key Features for my projects.
- **Experience Timeline**: A clean vertical tracking section displaying my education and qualifications.
- **Building & Learning Section**: Transparent cards indicating current focus areas and ongoing skill paths.
- **Mini Developer Terminal**: An interactive terminal simulator widget displaying details on command inputs like `whoami`, `skills`, `projects`, and `learning`.
- **Social Media Integration**: Programmatically mapped redirects opening LinkedIn, GitHub, and email links in a new tab.

## Built With

- **HTML5**: Structured semantic nodes and overlays.
- **CSS3**: Variables-driven styling system with glassmorphism effects, flex/grid layouts, and responsive queries.
- **Vanilla JavaScript**: Programmatic link mapping, modal controllers, terminal command simulator, and scroll behaviors.
- **Three.js**: Node-sphere particle mesh canvas rendering via CDN.

## Run Locally

The project is structured to run locally without build dependencies.
1. Open the project folder in **VS Code**.
2. Install the **Live Server** extension.
3. Click the **Go Live** button at the bottom right, or right-click `index.html` and select **Open with Live Server**.
4. Alternatively, double-click `index.html` to open it in a browser, or serve it using any local command (e.g. `python -m http.server 8000`).
